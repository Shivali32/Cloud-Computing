# Lab 1: Hadoop on Jetstream2

Configure and inspect a Hadoop installation on a Jetstream2 Ubuntu instance.

## How It Works

The report follows instance creation, access rules, Hadoop installation, and service configuration. Screenshots record the setup steps and the checks used to inspect the HDFS and processing environment.

## Main Tasks

- Prepare the virtual instance and access configuration.
- Configure Hadoop and its supporting services.
- Inspect the service and filesystem evidence in the report.
