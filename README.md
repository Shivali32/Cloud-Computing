# Cloud Computing

This repository contains Hadoop labs and the ShieldScrape cloud data-collection project from Engineering Cloud Computing. The first lab documents provisioning an Ubuntu instance on Jetstream2 and configuring Hadoop services. The second develops Python mapper and reducer programs for web-log analysis, including hourly IP counts and time-window filtering on a master/worker cluster. ShieldScrape combines archived scraping implementations with project reports and architecture diagrams about collecting league statistics, storing raw and cleaned records in S3, and preparing data for database queries and visualization. Its proposal records intended components and goals, while the source archives and later reports provide separate implementation and submission material.

## Assignments and Labs

- **[Lab 1: Hadoop on Jetstream2](Lab1/)**  
  Configure and inspect a Hadoop installation on a Jetstream2 Ubuntu instance.

- **[Lab 2: Hadoop Streaming Log Analysis](Lab2/)**  
  Process web-server logs with Python mapper and reducer programs on a Hadoop cluster.

- **[ShieldScrape: Cloud Data Collection](Midterm/)**  
  Collect and process football standings with archived scraping code and an AWS-oriented project design.
